\# Changelog



All notable changes to PITSysCodeGenerator will be documented in this file.



\## \[1.0.0] - 2024-01-15



\### Added

\- Initial release

\- Contract class generation with DataContractAttribute

\- Service class generation with process method

\- Controller class generation extending SysOperationServiceController

\- DataProvider class generation extending SysOperationRDPBase

\- UIBuilder class generation extending SysOperationAutomaticUIBuilder

\- MenuItem XML generation

\- WPF-based configuration dialog

\- Dynamic contract field management (add/remove fields)

\- D365FO naming convention enforcement

\- Output directory selection

\- Clipboard copy support

\- Bulk generation of all related classes
